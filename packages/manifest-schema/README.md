# Manifest schema

`schema-v1.json` is the original direct-assignment single-zone contract. `schema-v2.json` adds scheduling. `schema-v3.json` adds duration-bounded website items, hardened navigation policy, and optional downloaded fallback-image references. `schema-v4.json` adds an explicit expiring emergency takeover that references a prepared playlist without reinterpreting normal schedule priority. Go and Kotlin models map to these transport schemas rather than database rows. Released versions are not reinterpreted.
