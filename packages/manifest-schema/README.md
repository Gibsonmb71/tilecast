# Manifest schema

`schema-v1.json` is the original direct-assignment single-zone contract. `schema-v2.json` adds scheduling. `schema-v3.json` adds duration-bounded website items. `schema-v4.json` adds emergency takeover. `schema-v5.json` adds complete prepared playlists, `schema-v6.json` adds synchronized playback groups, `schema-v7.json` adds prepared Calendar Sources, and `schema-v8.json` adds prepared RSS, Atom, JSON, and CSV records. Go and Kotlin models map to these transport schemas rather than database rows. Released versions are not reinterpreted.
